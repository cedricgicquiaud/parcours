# Références UX — intrant pour la SPEC visuelle

Collectées en phase FIND (2026-08-14). Le cocktail visé pour Parcours :
la mécanique de The Odin Project, la structure de l'Anthropic Academy (Skilljar),
le format d'exercice de Total TypeScript, le soin typographique de Josh Comeau.

## Structure et progression

- **Anthropic Academy** (https://anthropic.skilljar.com) — la référence validée
  par Cédric : catalogue clair, page cours avec sommaire linéaire, barre de
  progression par cours, « reprendre où j'en étais ». Moteur : Skilljar (LMS).
  Ne pas copier ; s'inspirer de l'organisation.
- **The Odin Project** (https://www.theodinproject.com) — contenu 100 % markdown
  dans un repo GitHub, rendu web avec cases à cocher et progression par module.
  Preuve vivante du modèle « markdown + lecteur ».
- **web.dev Learn** (https://web.dev/learn) — modules, leçons courtes,
  auto-évaluations, typographie impeccable, pas de compte obligatoire.
- **Kaggle Learn** (https://www.kaggle.com/learn) — micro-cours, chapitres très
  courts, zéro friction.

## Expérience d'exercice

- **Total TypeScript** (https://www.totaltypescript.com) — « problème d'abord,
  solution ensuite » : la solution est une étape séparée révélée volontairement.
  Modèle pour les indices/solutions repliés.
- **EpicWeb.dev** (https://www.epicweb.dev) — instructions par étape, critères de
  réussite explicites, diff avant/après. Inspiration pour les critères cochables.
- **Exercism** (https://exercism.org) — états d'exercice clairs
  (à faire / en cours / réussi).

## Plaisir de lecture

- **CSS for JavaScript Developers** (https://css-for-js.dev, Josh Comeau) —
  typographie, encadrés, mini-interactions, mode sombre. Le haut de gamme du
  cours textuel ; référence de ton visuel, pas de périmètre.
- **Laracasts** (https://laracasts.com) — sommaire de série limpide avec durées
  et progression (vidéo-first, structure seulement).

## Quiz et interactif (V2 coach)

- **Brilliant** (https://brilliant.org) — répondre avant de lire l'explication.
  À garder pour les quiz V2, pas pour la V1.
