Une issue n'est pas une ligne figée : elle vit. Elle s'ouvre, se discute,
change de mains, se ferme — et peut rouvrir si le réel n'est pas d'accord.
Cette leçon fait le tour complet sur une issue d'essai.

## Deux états, et le fil qui raconte tout

Une issue est **Open** (badge vert : le travail reste à faire) ou **Closed**
(badge violet : terminé — ou abandonné, GitHub distingue « completed » et
« not planned »). Fermer n'efface rien : l'issue reste consultable pour
toujours, avec tout son fil d'activité. C'est la mémoire du projet.

Le **fil d'activité**, sous la description, enregistre chaque événement :
commentaires, changements d'état, assignations — qui, quoi, quand. Dans six
mois, il répondra à « pourquoi a-t-on décidé ça ? ».

## S'assigner : dire qui s'en occupe

**Assignees**, dans la colonne de droite, désigne la ou les personnes qui
travaillent sur la tâche. À trois sur un projet, c'est ce qui évite que deux
personnes fassent la même chose — ou que personne ne la fasse. S'assigner
soi-même se fait en un clic (« assign yourself »).

## Les sous-issues : découper sans perdre le fil

Une tâche trop grosse se découpe : le bouton **Create sub-issue**, sur la page
d'une issue, crée une issue fille rattachée à sa mère. La mère affiche alors
une barre d'avancement (« 1 of 3 ») qui se remplit quand les filles se
ferment. On s'en servira peu dans cette formation, mais sachez que ça existe :
c'est la réponse GitHub au « c'est trop gros pour une seule fiche ».

## Constatez-le sur pièce

Pas touche à votre issue de la leçon précédente — elle doit rester ouverte,
elle a un rendez-vous au module 5. Créez pour cet essai une issue jetable,
titre : `Essai du cycle de vie` (description libre, une ligne suffit). Puis,
sur elle :

1. **Assignez-vous** : votre avatar apparaît dans Assignees.
2. **Commentez** : écrivez une phrase dans la zone du bas, « Comment » —
   elle s'ajoute au fil, horodatée.
3. **Fermez** : bouton « Close issue ». Le badge passe au violet, la liste des
   issues ne l'affiche plus (elle est sous l'onglet « Closed »).
4. **Rouvrez** (« Reopen »), constatez le retour du badge vert — puis refermez
   pour de bon : l'essai est fini.

## Critères de réussite

- [ ] mon avatar apparaît dans Assignees de l'issue d'essai
- [ ] mon commentaire est dans le fil d'activité, horodaté
- [ ] j'ai fermé l'issue : badge violet, et elle a quitté la liste des issues ouvertes
- [ ] je l'ai rouverte puis refermée, et le fil d'activité raconte chaque bascule
- [ ] mon issue de la leçon précédente, elle, est toujours ouverte
